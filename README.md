# Manish Kumar Kondoju Portfolio

A colorful, technical portfolio built with React, TypeScript, Vite, and GSAP. The visual system combines cinematic gradients, data-inspired interface details, scroll storytelling, and responsive layouts.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Production build

```bash
npm run build
npm run preview
```

The optimized site is generated in `dist/`.

## Customize

- Portfolio content: `src/App.tsx`
- Colors, typography, spacing, and responsive behavior: `src/styles.css`
- Downloadable résumé: `public/Manish_Kumar_Kondoju_Resume.pdf`

## Deployment

The project can be deployed directly to Vercel, Netlify, Cloudflare Pages, or any static host. Use `npm run build` as the build command and `dist` as the output directory.
